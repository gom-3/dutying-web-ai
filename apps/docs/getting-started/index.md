# 듀팅 시작하기

듀팅은 병동 근무표를 작성하는 웹 서비스와 간호사의 개인 근무 일정을 확인하는 모바일 앱을 제공합니다. 먼저 이용 목적에 맞는 경로를 선택해 주세요.

## 병동 근무표를 작성하고 싶어요

1. [듀팅 웹](https://www.dutying.ai/)에 접속해 [회원가입](/web-guide/register) 또는 [로그인](/web-guide/login)을 진행합니다.
2. 관리할 [병동과 팀을 만들거나 기존 병동에 입장](/web-guide/wards)합니다.
3. [간호사 목록](/web-guide/nurses), 근무 유형, 근무별 필요 인원을 정리합니다.
4. [신청근무](/web-guide/requests)와 고정 근무를 확인한 뒤 [근무표 작성](/web-guide/schedule)을 시작합니다.
5. AI로 생성한 초안의 배정, 경고와 미충족 조건을 검토하고 필요한 내용을 조정합니다.

전체 준비 항목과 검토 순서는 [간호사 근무표 자동 생성 가이드](/guides/nurse-scheduling)에서 확인할 수 있습니다.

## 내 교대근무 일정을 관리하고 싶어요

[듀팅 iOS 앱](https://apps.apple.com/kr/app/id6804144827) 또는 [Android 앱](https://play.google.com/store/apps/details?id=ai.dutying.app&hl=ko&gl=KR)을 설치합니다. 모바일 앱에서 근무 캘린더와 개인 일정을 관리하고, 병동에 연결한 경우 병동 근무표와 소식을 확인할 수 있습니다.

설치 링크와 기능 설명은 [모바일 가이드](/mobile-guide/)를 참고해 주세요.
