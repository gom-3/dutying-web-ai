# 간호사 근무표 자동 생성 가이드

간호사 근무표 자동 프로그램은 병동의 근무자, 근무별 필요 인원, 휴무 요청과 근무 규칙을 바탕으로 월별 배정 초안을 만드는 도구입니다. 듀팅에서는 이 정보를 정리한 뒤 AI로 빈 근무를 채우고 결과를 검토할 수 있습니다. 최종 근무표는 병동 담당자가 배정과 조건을 확인한 뒤 확정해야 합니다.

## 간호사 근무표를 짜기 전에 무엇을 준비하나요?

| 준비할 정보 | 확인할 내용 |
| --- | --- |
| 근무자와 팀 | 이번 달 실제로 근무할 간호사와 소속 팀 |
| 근무 유형 | 병동에서 사용하는 근무 코드와 시간 |
| 필요 인원 | 날짜와 근무 유형별 필요한 간호사 수 |
| 신청근무 | 간호사가 요청한 근무와 휴무, 승인 여부 |
| 고정 근무 | 이미 확정해 변경하면 안 되는 배정 |
| 병동 규칙 | 연속 근무, 야간 근무, 휴식, 숙련도와 책임간호사 배치 등 병동에 필요한 조건 |

보통 D는 데이, E는 이브닝, N은 나이트, O는 오프(휴무)를 뜻합니다. 실제 표에는 병동에서 정한 근무 코드와 시간을 사용합니다. 같은 기호라도 병동에 따라 시간이 다를 수 있으므로 먼저 확인해 주세요.

## 듀팅에서 근무표를 자동으로 만드는 순서

1. [듀팅 웹](https://www.dutying.ai/)에 로그인하고 병동과 팀을 선택합니다.
2. 이번 달에 포함할 [간호사 목록](/web-guide/nurses)을 확인합니다.
3. 근무표 작성 화면에서 연월을 선택하고, 근무별 필요 인원과 병동 규칙을 설정합니다.
4. [신청근무를 검토](/web-guide/requests)하고, 이미 확정된 근무는 고정 근무로 확인합니다.
5. AI 자동 채우기로 근무표 초안을 생성합니다.
6. 근무표에서 필요한 인원이 충족됐는지, 경고와 미충족 조건이 있는지 검토합니다.
7. 필요한 배정을 조정한 뒤 담당자가 최종 근무표를 확인하고 확정합니다.

화면별 설명은 [근무표 만들기](/web-guide/schedule)에서 확인할 수 있습니다.

## 신청근무와 고정 근무는 무엇이 다른가요?

**신청근무는 간호사가 희망하는 근무나 휴무를 제출한 요청**입니다. 제출만으로 확정된 배정이 되는 것은 아닙니다. 담당자가 요청의 처리 상태와 배정 결과를 확인해야 합니다.

**고정 근무는 이미 확정해 그대로 유지해야 하는 배정**입니다. 자동 생성 전에 고정할 근무가 정확히 반영됐는지 점검해 주세요. 희망 사항을 모두 고정하면 다른 날짜의 필요 인원이나 휴식 조건을 맞출 여지가 줄어들 수 있습니다.

## AI가 만든 표는 무엇을 검토하나요?

- 날짜별·근무별 필요 인원이 충족됐는지 확인합니다.
- 확정된 고정 근무가 유지되는지 확인합니다.
- 야간 근무와 연속 근무, 휴식에 관한 병동 조건을 확인합니다.
- 숙련도와 책임간호사 등 병동 운영에 필요한 배치 조건을 확인합니다.
- 휴무와 야간 근무가 특정 구성원에게 몰리지 않는지 살펴봅니다.
- 표시된 경고와 충족하지 못한 요청을 읽고, 수정이 필요한지 판단합니다.

자동 생성은 담당자의 검토를 돕는 기능입니다. 모든 희망 조건을 동시에 충족하거나, 모든 병동에서 같은 시간 안에 표가 완성된다는 뜻은 아닙니다. 근무자 수와 설정한 조건에 따라 결과와 소요 시간이 달라집니다.

## 조건을 만족하는 표가 나오지 않으면 어떻게 하나요?

먼저 근무자 수에 비해 필요 인원이 과도하지 않은지, 같은 날짜에 고정 근무와 휴무 요청이 겹치는지, 야간·휴식 조건이 서로 충돌하는지 확인합니다. 필수로 지켜야 할 조건과 가능한 경우 맞출 선호를 구분하고, 화면에 표시된 미충족 조건을 바탕으로 조정해 주세요.

## 엑셀 근무표와 무엇이 다른가요?

엑셀에서는 셀을 직접 편집하며 인원과 조건을 확인하는 방식이 일반적입니다. 듀팅은 근무자, 병동 규칙, 신청근무를 함께 관리하고 AI 초안을 생성하는 흐름을 제공합니다. 도구를 바꾸더라도 근무표를 확정하기 전 인원과 배정 결과를 확인하는 과정은 필요합니다.
