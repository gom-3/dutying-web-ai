# 모바일 가이드

모바일 가이드는 아직 1차 구축 범위에 포함되지 않지만, 문서 사이트 구조에서는 초기에 자리를 확보합니다. 이렇게 해야 웹 전용 문서 사이트로 굳어지지 않고, 추후 모바일 앱 가이드를 같은 브랜드와 내비게이션 안에서 확장할 수 있습니다.

## 이후 추가될 후보 문서

- 앱 설치와 첫 로그인
- 내 근무표 확인
- 신청근무 제출
- 알림과 동기화 관련 안내

## 웹 문서와의 관계

- 병동 운영과 근무표 작성은 주로 웹 가이드에서 설명합니다.
- 근무표 확인과 개인 일정 활용은 모바일 가이드에 집중할 수 있습니다.
- 공통 개념은 시작하기 또는 FAQ에서 연결합니다.
