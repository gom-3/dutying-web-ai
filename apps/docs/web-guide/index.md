# 웹 가이드

현재 웹 문서는 병동 관리자 또는 근무표 작성자가 자주 거치는 흐름을 기준으로 시작합니다. 페이지 수를 많이 늘리기보다, 실제 사용자 여정이 보이는 최소 구조를 먼저 잡았습니다.

## 추천 순서

1. [로그인](/web-guide/login)
2. [회원가입](/web-guide/register)
3. [병동 생성/입장](/web-guide/wards)
4. [근무표 만들기](/web-guide/schedule)
5. [신청근무 관리](/web-guide/requests)
6. [간호사 관리](/web-guide/nurses)

## 이 섹션이 다루는 것

- 웹 앱 첫 진입과 계정 생성
- 병동 단위 협업 시작
- 근무표 작성과 운영 관리 흐름

## 후속 확장 방식

- 신규 문서는 사용자 행동 단위로 추가합니다.
- 특정 화면 기능이 복잡해지면 하위 문서로 분리합니다.
- 모바일 앱과 겹치는 개념은 별도 플랫폼 섹션으로 유지합니다.
