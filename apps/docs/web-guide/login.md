# 로그인

듀팅 웹 사용은 보통 로그인에서 시작합니다. 문서 사이트에서는 로그인 자체보다, 사용자가 로그인 후 어떤 흐름으로 이어지는지를 함께 설명합니다.

## 언제 필요한가요?

- 이미 계정이 있고 웹 앱에 다시 진입할 때
- 문서에서 바로 앱으로 이동해 작업을 시작할 때

## 기본 흐름

1. `app.dutying.net/login`으로 이동합니다.
2. 등록한 계정으로 로그인합니다.
3. 로그인 이후 병동 상태에 따라 메인 화면 또는 다음 작업 화면으로 이동합니다.

## 함께 확인하면 좋은 문서

- 아직 계정이 없다면 [회원가입](/web-guide/register)
- 병동이 없다면 [병동 생성/입장](/web-guide/wards)

## 추후 보강 예정

- 소셜 로그인 또는 인증 방식 정리
- 로그인 실패/세션 만료 시 재진입 가이드
