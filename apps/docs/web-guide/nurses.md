# 간호사 관리

간호사 관리는 병동 운영의 기반입니다. 문서 구조상 이 페이지는 구성원 등록, 연결 상태, 권한 정리 같은 주제를 담는 중심 페이지가 됩니다.

## 다루는 범위

- 병동 구성원 확인
- 간호사 정보 정리
- 연결 또는 초대 상태 확인

## 기본 흐름

1. 병동 운영에 필요한 구성원을 확인합니다.
2. 필요한 정보를 추가하거나 수정합니다.
3. 근무표 작성에 반영할 수 있도록 구성원 상태를 최신으로 유지합니다.
