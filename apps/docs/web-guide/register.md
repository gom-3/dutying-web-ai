# 회원가입

회원가입 문서는 웹 사용자가 듀팅을 처음 시작할 때 필요한 최소 안내를 담습니다. 실제 입력 항목 설명보다, 가입 이후 바로 이어지는 사용자 여정을 함께 묶는 것이 중요합니다.

## 이런 경우에 봅니다

- 새 병동을 만들기 전에 계정을 먼저 준비해야 할 때
- 기존 병동에 합류하기 전에 개인 계정이 필요한 때

## 기본 흐름

1. 웹 앱 회원가입 페이지로 이동합니다.
2. 계정을 생성합니다.
3. 가입 후 병동을 새로 만들거나 기존 병동에 입장합니다.

## 다음 단계

- 병동을 직접 만들 예정이라면 [병동 생성/입장](/web-guide/wards)
- 기존 병동 운영 정책에 맞춰 초대를 받아 합류하는 흐름도 같은 문서에서 함께 다룹니다.
