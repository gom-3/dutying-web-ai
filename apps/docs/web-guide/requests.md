# 신청근무 관리

신청근무 관리는 근무표 작성 전후에 반복적으로 확인하는 운영 작업입니다. 초안 단계에서는 이 문서를 별도 분리해, 이후 상세 정책과 운영 규칙을 추가할 수 있게 합니다.

## 언제 확인하나요?

- 근무표를 작성하기 전에 요청 현황을 먼저 볼 때
- 작성 중간에 신청 내용을 반영해야 할 때
- 마감 이후 예외 요청을 점검할 때

## 기본 흐름

1. 병동 또는 근무표 화면에서 신청근무 현황을 확인합니다.
2. 반영이 필요한 요청을 선별합니다.
3. 근무표 작성 흐름에 맞춰 조정합니다.

## 연결되는 문서

- 전체 작성 흐름은 [근무표 만들기](/web-guide/schedule)
- 구성원 상태와 권한은 [간호사 관리](/web-guide/nurses)
