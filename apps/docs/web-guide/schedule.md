# 근무표 만들기

근무표 만들기는 듀팅 웹의 핵심 작업입니다. 문서도 화면 기능 나열보다 실제 작성 흐름에 맞춰 정리하는 것이 중요합니다.

## 대표 시나리오

- 새로운 기간의 근무표를 생성할 때
- 기존 근무표를 수정하거나 보완할 때
- 자동 작성과 수동 조정을 함께 사용할 때

## 기본 흐름

1. 병동에 진입합니다.
2. 새 근무표를 만들 기간과 조건을 확인합니다.
3. 자동 생성 또는 직접 편집으로 초안을 만듭니다.
4. 구성원과 신청근무를 반영해 최종 조정합니다.

## 함께 보는 문서

- 신청근무 반영은 [신청근무 관리](/web-guide/requests)
- 구성원 상태 점검은 [간호사 관리](/web-guide/nurses)

## 추후 보강 예정

- 단계별 작성 화면 캡처
- 자동 생성과 수동 편집의 차이 설명
- 공개/공유 전 확인 체크리스트
