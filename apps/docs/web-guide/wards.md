# 병동 생성/입장

웹 사용자 여정에서 병동은 핵심 단위입니다. 계정을 만든 뒤 실제 협업을 시작하려면 병동을 생성하거나, 이미 운영 중인 병동에 입장해야 합니다.

## 이 문서가 다루는 흐름

- 새 병동 생성
- 기존 병동 입장
- 병동 진입 이후 첫 설정

## 기본 흐름

1. 로그인 또는 회원가입을 완료합니다.
2. 새 병동을 만들거나 초대/입장 흐름을 선택합니다.
3. 병동에 들어간 뒤 근무표 작성과 구성원 관리 기능을 사용합니다.

## 연결되는 작업

- 근무표를 처음 구성하려면 [근무표 만들기](/web-guide/schedule)
- 구성원을 정리하려면 [간호사 관리](/web-guide/nurses)
