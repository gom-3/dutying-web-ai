# 요청 해석 지연과 AI 사이드바 수정

개발계 요청 ca890307은 12,008ms에 성공했고, 10초 후 감지된 DB 연결은 응답 종료 때 반환됐다. InternalAccessPolicy.has()의 내부 호출은 capabilitiesOf()의 트랜잭션 프록시를 거치지 않는다. OSIV가 켜진 상태에서 권한 조회 연결을 외부 AI 대기까지 유지할 수 있다.

- 권한 확인 공개 진입점에 짧은 읽기 트랜잭션을 적용한다. OSIV 전체 설정은 바꾸지 않는다. 프록시 및 OSIV 환경에서 연결 반환을 회귀 검증한다.
- 명확한 단일 휴무 개수 지정은 엔진에서 제한된 전체 문장 매칭 후 기존 normalize 검증을 통과시킨다. 부정·특정 간호사·복합 요청·기간·이전 대화는 기존 모델 경로를 유지한다. 실제 모델 호출 없이 처리되는지 검증한다.
- AI 진입 버튼을 하나로 합친다. 사이드바 안에서 자동채우기와 수정 요청을 구별하고 재생성 확인을 보존한다. 대화형 기능 플래그를 강제로 활성화하지 않는다.
- 본문은 16px, 보조 정보는 최소 14px, 짙은 대비를 사용한다. 저장된 요청과 새 요청을 확인하는 단계는 유지한다.
- 해석 대기 중 경과 시간을 표시하고, 늦어질 때 현재 상태와 재시도 안내를 제공한다. 결과를 받기 전에는 실행하지 않는다.

DB 스키마 변경 없음. develop 반영 후 개발계 빌드/상태와 공개 Web 배포를 확인한다.
