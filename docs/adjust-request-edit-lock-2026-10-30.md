# 자동완성 요청 확인과 조절 첫 사용 안내

- 요청 해석 중에는 화면의 근무표, 키보드/붙여넣기, 행 이동, 저장·확정, 단계 이동을 잠근다. 실행 상태와 별도로 전달해 사이드바를 닫거나 생성 로딩 화면을 띄우지 않는다. 완료·실패·취소·unmount 시 해제한다.
- 조절 가능한 기존 근무표의 대화를 처음 열 때 계정별 사용법 안내 모달을 보여준다. 확인한 뒤 같은 브라우저에서 반복하지 않는다. 고정 근무 보존, 요청 예시, 결과 확인·되돌리기를 설명한다.
- 단순 자동완성 명령은 기존 생성 준비/재생성 확인 경로로 보낸다. 추가 조건·답변·수정 요청은 기존 서버 해석을 유지한다. 자동 실행이나 보호 계약 생략은 하지 않는다.
- 진행상황 보기는 대화를 여는 동작으로만 유지한다. 첨부 로그의 17:37 두 실행은 접수 후 서버 EXECUTION_FAILED이며, UI 클릭과 인과관계는 로그 확인 전 단정하지 않는다.
- API/DB 변경 없음. Flyway migration 없음.

## 검증

- 관련 Vitest 6파일 310개 통과. 첫 사용 안내의 계정/관리자 구분 변경 후 안내 테스트 별도 통과.
- TypeScript 프로젝트 빌드 및 변경한 제품 코드 ESLint 통과.
- 첨부 사건과 개발 서버 로그 모두 17:37 두 생성이 HTTP 202 이후 schedule-background의 IllegalStateException으로 종료됨을 확인했다. 진행상황 열기에서 취소 API를 호출하는 코드는 없다.
- 별도 Spring 수정 브랜치: fix/background-request-locale-snapshot. 요청에 묶인 LocaleContext를 작업 제출 시점의 언어/시간대 값으로 복사한다.
- 개발/운영 배포와 실서비스 재시도는 수행하지 않았다.
