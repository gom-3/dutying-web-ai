# 첫 온보딩 입력·수정 측정 계약

서버의 `docs/analytics/onboarding-dashboard-design.md`와 함께 관리한다. 기존 웹 가입·병동 사용 대시보드의 첫 온보딩 코호트에 사용한다.

초안의 `onboardingSignals`를 autosave와 복원, 최종 병동 생성 요청에 보존한다. 신규 초안만 coverageComplete=true이며 기존 초안에 필드가 없으면 미수집으로 유지한다. EXCEL/PHOTO 성공 적용 시 가져오기 신호, 사용자의 실제 근무유형/가능근무/제약조건 변경 시 boolean을 단조 누적한다. 자동 추출·프리필·초안 복원은 직접 수정으로 세지 않는다. 수정 후 원복해도 수정 경험은 true다. 같은 값 재선택은 변경이 아니다.

이름, 파일명, 자유문, 실제 근무 내용이나 식별자를 새로운 신호에 보내지 않는다. 기존 draftPayload에는 원래 편집 복원을 위한 데이터가 있고, 서버는 별도의 소형 요약만 완료 후 보존한다. 이전 클라이언트 요청은 호환하며 false로 소급하지 않는다. 첫 병원·병동 서버 저장 전 이탈은 이 계측에 포함되지 않는다.

운영 반영은 서버 V81 이후 웹 순서. develop 반영과 실제 운영 배포·실사용 검증은 별도다.
