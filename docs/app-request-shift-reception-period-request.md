# 신청근무 접수 기간 제한 앱 개발 요청

## 목적

병동에서 신청근무 접수 기간 제한을 사용하는 경우, 간호사는 앱에서 해당 기간에만 다음 달 신청근무를 제출하거나 수정할 수 있어야 합니다.

설정을 사용하지 않는 병동은 기존과 동일하게 동작합니다.

## 앱 동작

앱은 신청근무 화면 진입 시 대상 월의 접수 상태를 조회합니다.

### 상태 조회

`GET /wards/{wardId}/req-shifts/reception-status?year=2026&month=7`

```json
{
  "enabled": true,
  "status": "OPEN",
  "canSubmit": true,
  "opensAt": "2026-06-01T09:00:00+09:00",
  "closesAt": "2026-06-15T23:59:00+09:00",
  "serverNow": "2026-06-10T13:30:00+09:00"
}
```

## 상태별 UI

### `UNLIMITED`

- 기존과 동일하게 신청/수정 가능
- 별도 제한 문구 표시 없음

### `BEFORE_OPEN`

- 신청/수정 불가
- 신청근무 달력은 조회 가능
- CTA/셀 선택/저장 액션 비활성화
- 문구 예시: `7월 신청근무는 6월 1일 09:00부터 신청할 수 있어요.`

### `OPEN`

- 신청/수정 가능
- 접수 종료 시점 표시
- 문구 예시: `7월 신청근무 접수 중이에요. 6월 15일 23:59까지 수정할 수 있어요.`

### `CLOSED`

- 신청/수정 불가
- 신청근무 달력은 조회 가능
- CTA/셀 선택/저장 액션 비활성화
- 문구 예시: `7월 신청근무 접수가 마감됐어요.`

## 제출/수정 요청 실패 처리

앱에서 화면을 연 뒤 접수 상태가 바뀔 수 있으므로, 저장 API 실패도 처리해야 합니다.

기간 밖 에러 예시:

```json
{
  "code": "REQ_SHIFT_RECEPTION_CLOSED",
  "message": "신청근무 접수 기간이 아닙니다.",
  "receptionStatus": "CLOSED",
  "opensAt": "2026-06-01T09:00:00+09:00",
  "closesAt": "2026-06-15T23:59:00+09:00"
}
```

처리:

- 토스트 또는 하단 안내로 저장 실패 표시
- 접수 상태를 다시 조회
- 화면을 읽기 전용 상태로 전환

## 푸시 알림

앱은 백엔드 푸시를 수신하고 신청근무 화면으로 이동할 수 있어야 합니다.

알림 종류:

- 접수 시작: `7월 신청근무 접수가 시작됐어요.`
- 마감 24시간 전: `7월 신청근무 접수가 곧 마감돼요.`

권장 payload:

```json
{
  "type": "REQ_SHIFT_RECEPTION",
  "event": "OPEN",
  "wardId": 1,
  "year": 2026,
  "month": 7
}
```

`event` 값:

- `OPEN`
- `CLOSING_SOON`

마감 후 알림은 1차 범위에 포함하지 않습니다.

## 1차 제외

- 마감 후 예외 신청
- 임시 재오픈
- 마감 후 알림
- 앱에서 관리자에게 예외 요청 보내기

기간 밖에서는 앱 신청/수정만 막고, 이미 제출된 신청근무 조회는 유지합니다.
