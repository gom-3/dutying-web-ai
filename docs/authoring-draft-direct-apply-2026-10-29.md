# 편집 초안 결과 즉시 반영 (2026-10-29)

사용자 변경 정책: 유효한 생성·조절 결과는 기존 스냅샷/undo 이력과 함께 편집 중 표에 즉시 반영한다. 조건 위반은 검증 진단과 기존 표의 조건 표시로 유지하며, 후보 선택·TTL·추가 동의로 초안 적용을 막지 않는다. 최종 확정/게시 경로는 바꾸지 않는다.

Spring은 기존 응답 검증(엔진 계약, 결과 digest, 소속·날짜·근무종류·고정칸·채워진 칸 보호, 완전성, plan/source/revision)을 유지한다. 업무조건 충족·위반 증감·변경량·정성 검토는 진단이며 초안 적용 승인 조건이 아니다. 실행 중 편집 충돌은 기존 source/revision 검사로 적용하지 않고 최신 표를 보존한다. 엔진 실패/불완전/무결성 오류는 실패로 남긴다.

Web은 Spring에서 실제 APPLIED된 결과만 최신 로컬 revision에 복원하고 기존 이력과 검증표시를 보존한다. 후보 선택 및 사이드바 중복 조건 위반 목록은 제거한다. 성공 표시는 표에 적용한 결과에만 사용한다. 기존 재동기화/undo를 사용하며 새 확인 UI나 재시도 루프는 추가하지 않는다.

집중 회귀: 정상 생성·조건 위반 초안·조절·undo·동시 편집 보호, 실패/무결성 거부. Engine 파일은 다른 재현 작업 소유이므로 수정하지 않는다. DB/Flyway 변경 없음.
