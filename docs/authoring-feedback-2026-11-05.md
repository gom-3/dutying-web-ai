# 수정 결과 설명
기존 결과 카드의 제목 아래에 실제 검증 상태에 따른 설명을 표시한다. 시간 초과, 후보의 보호 조건 위반, 변경량 상한, 개선안 미발견을 구분한다. 개선안 미발견을 불가능 증명으로 안내하지 않는다. 적용/이전 표 결과에는 실패 설명을 표시하지 않는다. API 계약/승인 정책 변경 없음.

검증: 결과 설명·승인 조건·결과 카드 40개 테스트 통과, TypeScript tsc -b 및 변경 파일 ESLint 통과. 한국어/영어/일본어 제공. 기존 테스트에서 React act 경고가 출력되지만 실패 없음. 운영 화면/실서비스 E2E는 미검증.
