# 자동완성 충돌 확인 복구

## 근거

병동 733 / 팀 1158의 2026-11-03 실행에서 서버는 CONFLICT_REVIEW와 후보 토큰을 반환했지만 직접 실행 UI는 토큰을 버려 확인 버튼 대신 재계산을 노출했다. 실제 엔진 입력 archive 234~237 모두 최연희 11월 1일 N fixed=true다. normalizeDraftCellsForAiPatch가 최신 사용자 입력을 확정 스냅샷 고정값으로 덮는다. 후보 탐색은 최대 20초이며, 동의 시 재계산 없는 캐시 재검증 경로가 이미 존재한다.

## 변경 계약

- 사용자가 편집한 현재 초안을 AI의 원본으로 사용한다. 확정 스냅샷은 누락 셀의 기본값으로만 사용하고 명시적으로 제출된 셀을 덮지 않는다. 수락된 신청근무는 서버 보호를 유지한다. AI는 제출된 고정 셀을 변경하지 않는다.
- 직접 실행의 충돌 후보 토큰과 원본 문서/판본/요청을 화면에 보관한다. 충돌의 사람·날짜·설정 대비 결과를 보여주고 이번 실행 동의를 묻는다. 동의는 동일 입력+토큰+conflictConfirmed=true로 제출한다. 표/조건/범위가 바뀌면 후보를 사용할 수 없다.
- 검증된 후보가 있으면 일반 재계산 버튼을 숨긴다. 후보가 없는 실제 불능은 구체적 근거와 수정 행동을 남기고 포괄적인 반복 문구를 제거한다.
- 자동으로 표시되는 대화 수정 소개 모달을 제거한다.
- 충돌 후보 탐색의 기존 안전 검증은 유지한다. 확인 토큰 재사용이 지연 개선의 우선 경로다. 실제 운영 속도 개선은 별도 측정 없이 주장하지 않는다.

## 검증

Spring: 확정본 N → 현재 초안 OFF/빈칸/잠금 해제 보존, 누락 셀 기본값, 수락 신청근무 보호 회귀 테스트.
Web: 직접 실행 후보 확인 표시/토큰 재전송/변경 후 무효화, 후보가 있을 때 재계산 숨김, 반복 안내 제거, 기존 대화 후보 테스트.
DB 스키마 변경 및 Flyway migration 없음. 개발 DB 접근 불필요. 운영 배포는 이 작업 범위에 포함하지 않는다.
