# 자동채우기 첫 요청과 변경 내역 요약

- 시작 선택 화면에 이번 표에만 적용할 자유 입력을 둔다. 빈 값은 기존 생성 요청을 그대로 보낸다.
- 값이 있으면 기존 대화 `interpretations` 계약으로 한 번 해석하고, 준비된 계획을 첫 `GENERATE` 실행에 연결한다. 모호한 계획은 기존 질문을 거치며, 실행 뒤에도 같은 대화 상태로 정정·취소한다.
- Spring은 확인된 의미 계획이 있는 첫 생성도 허용한다. 엔진의 기존 `intent-first-v1` 생성과 검증을 사용한다. 월별 요청을 영구 규칙으로 승격하지 않는다.
- 실제 적용된 `changedCells`의 건수를 접힌 버튼에 보이고, 펼칠 때만 기존 이전 버전을 읽어 날짜별 이전·이후를 표시한다. 새 결과는 접힌 상태로 시작한다.
- 검증: 빈 입력 경로, 입력 계획의 생성 연결과 후속 대화, 토글 접근성 및 새 결과 초기화, 서버 계약 테스트, 격리 QA의 실제 UI.
