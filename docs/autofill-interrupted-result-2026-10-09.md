# 중단된 자동완성의 결과 보존 (2026-10-09)

## 문제
사용자에게 계산 제한시간을 실패 원인으로 표시했다. 또한 생성 모델이 중단되면 규칙을 지킨 표를 진단 과정에서 찾아도 버리고, 검토 초안 경로는 INFEASIBLE에만 열려 있었다.

## 계약
- 자동완성의 전체 계산 예산은 늘리지 않고 첫 탐색에 75%를 사용해 결과 확보 여유를 남긴다. 조절에는 이 분할과 규칙 완화를 적용하지 않는다.
- 같은 필수 조건을 유지한 추가 탐색에서 확보한 완전한 표는 원래 조건으로 다시 검증해 반환한다. 최적성을 증명했다고 표시하지 않는다.
- 첫 표가 없는 중단도 기존 검토 초안 경로의 대상에 포함한다. 원본 고정 근무·허용 근무 종류·기간은 유지하며 원래 조건의 미충족 내용을 표시한다. 검증되지 않은 결과를 적용하지 않는다.
- 모든 탐색은 같은 전체 마감 시각을 따른다. 필수 조건 탐색의 후속 계산은 남은 시간의 절반까지만 사용해 검토 초안 탐색 여유도 남긴다. 반환 가능한 표가 없으면 서비스 문제로 안내하며 제한시간/최적화/솔버를 사용자에게 실패 이유로 제시하지 않는다. 조건 충돌은 실제로 확인한 경우에만 설명한다.

## 검증
첫 탐색 중단 후 실제 CP-SAT에서 완전한 초안을 확보하는 사례, 원본 고정·유효 코드 유지, 조절 미완화, 전체 마감 준수, 후보가 없는 실제 서비스 오류의 문구와 채팅 이력 유지.

기존 `test:ai-scenarios --engine-repo`에도 결과 보존과 API 검증 테스트를 포함해 같은 문제가 다시 생기면 시나리오 파이프라인에서 발견한다.
