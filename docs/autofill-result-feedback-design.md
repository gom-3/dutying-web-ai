# 자동완성 결과 만족도 수집

## 목적
자동완성이 실행됐는지와 수간호사가 결과에 만족하는지를 구분한다. 결과 적용 직후 ‘방금 만들어진 근무표, 마음에 드나요?’를 표시한다.

## 결정
- 마음에 들어요 / 아쉬워요 선택, 이유는 선택 입력(500자), 보내기 / 나중에. 전송 중·성공·실패 및 재시도 상태를 표시한다.
- 자동완성 결과가 실제 화면에 적용된 뒤에만 노출한다. 실패, 적용하지 않은 후보, 조절 결과에는 노출하지 않는다.
- 기존 대화형·일반 자동완성 모두 지원한다. 결과별 식별자를 사용하고 다른 결과로 답변이 섞이지 않게 한다.
- 피드백은 조절 요청과 분리한다. 전송으로 근무표·제약조건·대화를 변경하지 않는다.
- 기존 journey-events API에 USER_FEEDBACK 유형, satisfaction(LIKED/NEEDS_WORK), feedbackNote를 추가한다. 동일 eventId 재전송은 멱등 처리한다. 소유자·병동·팀·서버 결과를 검증한다.
- 기존 schedule_journey_event JSON 저장소와 어드민 사용자 흐름 화면을 사용한다. 별도 사건 경보를 만들지 않는다. DB 스키마/Flyway 변경 없음.
- 어드민에 만족도·이유·대상 결과를 표시한다. 긍정/부정 의견은 기술적 성공률과 별도 집계한다.

## 검증
다른 사용자/병동 결과 거부, 실패·미적용 결과 거부, 잘못된 평점/초과 길이 거부, 중복 전송 멱등성, 전송 실패 후 재시도, 결과 변경 시 입력 초기화, 키보드 접근성, 한국어/영어 문구, 조절 호출 없음.
