작성 중 경고와 확정 전 검증

빈 근무표 전체를 오류로 표시하지 않고, 배정한 근무에서 확인된 실제 위반을 보여준다. 빈칸과 최소 인원 부족은 확정 직전 전체 검증으로 확인한다.

상황작성 중확정 직전
빈 표 / 미입력 셀위반 오버레이 없음이번 달 빈칸 수 안내
최소 배정·동반·책임 인원 부족보류전체 위반 목록 안내
금지 근무 조합 / 연속 근무 초과배정한 셀에 즉시 표시전체 검증
최대·정확 인원 초과즉시 표시전체 검증
기간별 최소 근무·휴무 횟수대상 행과 기간이 완성된 경우만 표시전체 검증

API 계약

POST …/validate-snapshot에 validationPhase: "DRAFT" | "FINAL"을 추가한다. 생략은 기존 FINAL이다. 웹 실시간·재진입 요청의 기본값은 DRAFT, 확정 직전 요청은 FINAL이다. 응답 draftViolations는 작성 중 표시용 목록이며, AI 결과 등 전체 검증 응답에도 제공한다. violations와 summary는 요청 단계에 맞는 결과다. 엔진 판정과 확정본 기록은 기존 전체 검증을 유지한다.

확정 흐름

최신 표를 FINAL로 검증한 후 빈칸이나 위반이 있으면 기존 형식의 대화상자에서 수와 상세 목록을 보여준다. ‘돌아가서 수정’ 또는 ‘이대로 확정’을 선택한다. 기존의 사용자 판단에 따른 위반 포함 확정 정책은 유지한다. 검증 실패·응답 판본 불일치·검증 도중 표 또는 병동/팀/달이 변경되면 저장과 확정을 중단한다. 스냅샷 한도 경로에서도 삭제 전에 검증한다.

반영 범위

Spring DTO·표시 정책·검증 API와 웹 API 타입·검증 요청·오버레이·확정 전 확인 흐름을 변경한다. Flyway migration 없음. 개발/운영 배포는 별도다. 서버의 신규 응답 계약이 먼저 반영되어야 웹의 작성 중 표시 정책을 완전히 적용할 수 있다.

검증

빈 표, 부분 입력, 실제 금지 조합·초과 위반, 기간별 횟수, AI 전체 결과의 작성 중 표시, 확정 전 부족 경고·빈칸 검토·검증 실패·입력 변경 경쟁을 로컬 회귀 테스트로 확인한다.
