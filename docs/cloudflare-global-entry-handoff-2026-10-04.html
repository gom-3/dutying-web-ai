Dutying 글로벌 첫 방문 현지화

방문자가 기본 주소로 들어오면 접속 국가에 맞는 언어 페이지를 바로 보여줍니다. 기존 언어별 페이지와 한국어 기본 주소의 검색 색인은 유지합니다.

작성일 2026-10-04대상 www.dutying.ai대상 빌드 pnpm build:appDB 변경 없음

담당자에게 필요한 작업

  1. 웹 코드가 반영된 배포에서 apps/app/dist/_worker.js와 apps/app/dist/_routes.json이 함께 게시되는지 확인합니다. Pages 프로젝트의 빌드 명령은 pnpm build:app, 출력 경로는 apps/app/dist입니다.
  2. Pages Functions가 /와 /__visitor-country에서만 실행되는지 확인합니다. /ja, /en, 이미지·JS·CSS는 정적 자산으로 제공되어야 합니다.
  3. 기본 주소에 별도의 Cloudflare Redirect Rule 또는 캐시 규칙을 중복 추가하지 않습니다. 리디렉션은 배포된 Worker가 처리합니다.
  4. 무료 한도 초과 시 정적 페이지를 계속 제공하도록 Pages의 Settings → Runtime → Fail open / closed를 Fail open으로 설정하고, Functions 사용량 알림을 확인합니다.

동작 정책

언어 선택 우선순위는 명시한 ?lng → 저장된 언어 → 접속 IP 국가 → 브라우저 언어 → 영어입니다. 자동 이동은 기본 주소 /에서만 임시 302 응답으로 실행하고, 리디렉션 응답은 private, no-store로 반환합니다.

현재 중국어 페이지는 간체입니다. 대만의 번체 현지화는 별도 번역 작업이 있어야 하므로 IP 국가 TW를 간체 페이지로 자동 연결하지 않습니다.

사용자가 /ja처럼 언어 주소를 직접 방문하면 IP 국가와 관계없이 그 페이지를 그대로 제공합니다. 언어 선택은 쿠키에 보관하며, 로그인 후 계정의 선호 언어도 기존처럼 적용합니다. 화면 언어 변경은 계정의 서비스 지역을 변경하지 않습니다.

알려진 검색 크롤러가 기본 주소에 접근하면 한국어 정적 페이지를 반환합니다. 일반 방문자는 브라우저 언어 헤더가 없어도 IP 국가를 우선 적용합니다.

국가 선택 질문은 추가하지 않습니다. 계정에 서비스 지역이 아직 없을 때 웹이 접속 국가에서 추정한 지역을 API 헤더로 보내고, 기존 서버가 이를 최초 지역으로 저장할 수 있습니다. 이미 저장된 계정 지역은 IP가 바뀌어도 유지됩니다. 한국 병원 목록만 현재 방문 국가를 기준으로 판단하므로 여행·VPN으로 추정이 틀린 경우에도 병원명 직접 입력은 가능합니다.

기술 구성

  • Cloudflare Pages의 배포 산출물 _worker.js가 request.cf.country를 읽습니다. 별도 GeoIP API, GPS 권한 또는 IP 주소 저장은 사용하지 않습니다.
  • _routes.json의 include는 /와 /__visitor-country뿐입니다. 정적 페이지·이미지·번들은 Function 요청 한도를 사용하지 않습니다.
  • /__visitor-country는 브라우저에 두 글자 국가 코드 또는 null만 반환하고 캐시하지 않습니다. 제품 화면은 한 번 조회한 국가를 탭 세션에 보관합니다.
  • 기존 www.dutying.ai가 정식 사이트입니다. app.dutying.ai는 동일 앱의 호환 주소이며, dev.dutying.ai는 별도 Pages 프로젝트입니다.
  • Java API 서버나 DB 스키마 변경 없이 이 동작을 적용합니다. 웹의 언어→서비스 지역 자동 매핑을 제거했고, 병원 목록은 계정의 과거 지역값 대신 방문 국가를 사용합니다.

검색엔진은 언어별 고정 주소를 직접 읽어야 합니다. 국가별 리디렉션을 /* 전체에 적용하거나 /ja를 다른 언어로 보내지 마세요. 운영 반영 후 Search Console에서 국가별 색인과 검색 노출을 확인합니다.

요금·장애 대응

Cloudflare 공식 문서 기준 Pages Function은 Workers 무료 한도에 포함되며, 무료 한도는 두 기능을 합쳐 하루 10만 호출입니다. 정적 자산 요청은 무료입니다. 이 구현은 두 경로만 Function을 사용하므로 유료 전환은 필수가 아닙니다. 한도 초과로 Function이 실행되지 않으면 Fail open 설정에 따라 정적 한국어 기본 페이지와 언어별 직접 주소는 계속 제공됩니다.

문제 발생 시 배포 이전 버전으로 Pages 롤백하면 됩니다. 대시보드에 별도 리디렉션 규칙을 만들지 않았으므로 별도 규칙 삭제 작업은 없습니다.
