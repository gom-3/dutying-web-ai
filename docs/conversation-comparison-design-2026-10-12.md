# 대화형 근무표 변경 내역

## 원인
REBUILD_UNLOCKED는 Spring의 rebuildInputCells에서 미고정 근무를 비운 뒤 엔진에 전달한다. 엔진 quality_sidebar_response는 이 cells를 비교 기준으로 사용한다. 따라서 저장된 이전 버전이 완성되어 있어도 BASELINE_INCOMPLETE가 나온다. 이는 저장된 이전 근무표가 사라진 증거가 아니다. 엔진의 비교 기준을 바꾸면 생성 제약/목적함수에 영향을 줄 수 있으므로 이번 표시 수정에서 생성 입력은 변경하지 않는다.

## 표시 계약
- 실제 변경 내역은 Spring이 원본과 결과를 비교한 result.changedCells를 사용한다. 간호사별 변경 칸 수와 날짜를 접힌 목록으로 제공한다. 기존 전후 비교 버튼은 저장된 버전을 연다.
- 품질 지표는 휴무 목표 차이, 최소 휴식 시간, 신청 반영률 중 유효한 before/after가 있는 항목만 보여준다. 0명 비교와 불리해진 0명을 함께 표시하지 않는다.
- 추상적인 야간 평균 편차/분절률/엔진 changedCells는 사용자용 품질 요약에서 제외한다. 전체 엔진 관계도 일부 지표만 표시하는 화면에서 재사용하지 않는다.
- 비교 가능한 지표가 없으면 이유를 한 문장으로 표시한다. 이전 표에 빈칸이 있다고 단정하지 않는다. 알 수 없음의 개인별 반복, 무의미한 0명 집계는 제거한다.
- 품질 비교가 있는 경우 악화 항목/간호사를 먼저 보여주고 변경된 유효 지표만 개인별 상세에 표시한다. 월경계 휴식 누락 등 해석에 필요한 한계는 접힌 비교 범위로 제공한다.
- 저장된 과거 결과에도 적용한다. 서버/DB/계산/배포 변경 없음.

## 검증
정보가 없는 25명, 일부만 비교 가능, 0 변경, 실패/미반영 결과, 잘못된 수치, 실제 변경 날짜와 건수, 기존 제안 흐름 회귀를 확인한다.

## 확인 결과
- evidence 및 sidebar 테스트 61개 통과, tsc -b 통과.
- 로컬의 기존 3회차(25명/450칸)에 즉시 반영 확인. 김지인 16칸의 변경 날짜 표시 확인.
- 저장된 전후 비교에서 변경 전/변경 후 전환 확인. 추가 생성이나 근무표 확정은 하지 않음.
- 한계: 재생성 품질지표의 실제 원본 기준 계산은 엔진 계약 변경이 필요하며 이번 변경에 포함하지 않음. 비교할 수 없는 지표를 계산된 것처럼 보여주지 않음.
