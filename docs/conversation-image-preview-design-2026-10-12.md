# 대화 속 근무표 이미지

완료 카드 상단에 저장된 결과 버전의 근무표 캡처를 직접 표시한다. 현재 편집 표를 캡처하지 않으며 이후 편집에도 과거 이미지는 바뀌지 않는다. 이미지를 누르면 같은 이미지를 확대/축소할 수 있는 대화상자를 연다. 기존 표 보기/전후 비교는 유지한다.

성능: 화면에 들어온 카드만 버전을 읽고 정적 캘린더를 잠시 렌더링한다. html-to-image는 필요할 때 로드하며 캡처를 순차 실행한다. 캡처 뒤 캘린더 DOM을 제거하고 Blob 이미지만 표시한다. 메모리 캐시는 최대 8개/16MB로 제한하고 object URL은 컴포넌트 해제 시 반환한다. 파일 업로드나 브라우저 영구 저장은 하지 않는다. 실패 시 재시도/기존 표 보기 경로를 유지한다.

검증: 캐시/순차 실행/실패 후 재시도/확대 시 재캡처 없음/URL 반환/기존 스냅샷과 사이드바 테스트 총 59개 통과. tsc -b 및 Vite build 통과. 로컬 3회차의 실제 캡처(1920×1476) 표시, 확대/화면 맞춤 확인. 기존 1~3회차 모두 독립 이미지로 표시됨. 추가 생성·확정·PR·배포 없음.

## 사용자 정보 최소화 (최종)
완료 카드에서 변경 칸 집계/간호사별 변경 토글/품질 비교/비교 불가 사유를 제거한다. 결과 이미지와 실제 규칙·미충족 요청 경고를 우선 표시하며 저장된 이전 근무표 비교는 사용자가 선택할 때만 연다. 실패 해결에 필요한 구체적인 조건 변경 제안은 유지한다.
