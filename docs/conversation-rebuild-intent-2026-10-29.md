# 대화에서 조절과 전체 재작성 이어가기 (2026-10-29)

표 편집은 계산을 시작하지 않는다. 상단 자동채우기는 편집 여부와 관계없이 빈칸·조건·신청 변경에 사용할 수 있다.
입력은 최신 draft를 동기화하고 기존 의도 해석 한 번으로 처리한다. 구체적인 변경은 ADJUST를 유지한다.
명확한 전체 재작성만 같은 해석의 generationIntent 원문 근거로 표시한다. 단어/정규식 라우팅과 새 모델 호출은 없다.
재작성 준비의 사용자 대기 시간은 기존 GENERATE 계산 예산에 포함하지 않는다. 계획 유효기간·hash는 유지하고 최종 실행에서 기존 GENERATE 계산 예산을 시작한다. ADJUST의 기존 단일 실행 창은 유지한다.
재작성도 REVIEW 절과 다른 요청 절을 모두 보존하며 기존 준비(전월·신청·고정·수동 변경)와 확인을 거친다.
서버는 최신 확인된 계획·source·hash·유효기간과 REBUILD_UNLOCKED 동의를 검증한 GENERATE만 허용한다.
준비 중 source가 바뀌면 기존 refreshPlan을 사용한다. 자동 실행은 재작성에 허용하지 않는다.
취소는 표를 지우지 않고 임시 보호만 복원한다. 후보/동의/중복 방지와 전월 carryOver 계약은 유지한다.
대화 상태의 과거 재작성은 다음 입력의 재작성 권한이 아니다. 현재 추가/수정한 조건의 근거만 전달한다.
레거시는 같은 해석 응답의 근거를 확인해 기존 생성 준비로 연결하며 원문을 실행 prompt에 보존한다.
새 모드·카드·설정, 모델 교체, solver 목적함수와 DB/Flyway 변경은 없다.

검증: 최신 표 조절, 재작성 확인/취소, 준비 후 계획 갱신, 조건만 변경한 자동채우기,
빈 입력·중복 제출·오래된 후보·실패 재시도와 기존 프롬프트 전달을 집중 회귀한다.
