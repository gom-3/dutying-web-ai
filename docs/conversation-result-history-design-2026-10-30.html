AI 결과 자동 반영과 이력 복원

AI 대화 아래의 근무표 확정 버튼은 이미 표에 반영된 결과를 다시 승인하는 단계처럼 보인다. 대화에서는 이 버튼을 제거하고, 변경 내역과 반영 취소·다시 반영을 제공한다. 근무표 도구 모음의 독립적인 배포 기능은 유지한다.

서버는 계산 전 sourceVersion과 계산 후 resultVersion을 저장한다. 표가 계산 중 수정된 경우에도 resultVersion을 저장하지만 NOT_APPLIED_SOURCE_CHANGED로 분류한다. 이 저장본을 실패로 표현하지 않고 이력에 저장되었다고 안내하며 복원 기능을 제공한다. 검증된 APPLIED 또는 NOT_APPLIED_SOURCE_CHANGED 결과만 복원 대상으로 삼고 미검증 후보는 포함하지 않는다.

복원 전 수동 편집을 서버 버전으로 동기화하고 복원 이후 취소하면 그 버전으로 돌아간다. 대화나 실행 기록을 삭제하거나 솔버를 다시 실행하지 않는다. 기존 revision 검사와 복원 확인 대화상자를 유지하고 현재 고정·신청 근무와 다른 저장본은 복원하지 않는다. 고정 표시도 유지한다.

검증: 자동 반영, 중복 확정 버튼 제거, 계산 중 변경된 결과의 복원·취소·재접속, 기존 수동 편집 보관, 복원 도중 편집 경합, 고정 근무 보호를 관련 컴포넌트 테스트로 확인한다. 서버 계약과 DB 변경은 없다.

개발 싱크 결과

대상: dutying-web-ai. 관련 테스트 5개 파일의 238개 사례 통과, TypeScript tsc -b 통과, 변경된 컴포넌트·번역·테스트 ESLint 통과, git diff --check 통과. 실제 LLM 호출과 배포는 수행하지 않았다. 서버의 기존 불변 결과 버전을 스냅샷으로 재사용하므로 API·DB 변경은 없다.
