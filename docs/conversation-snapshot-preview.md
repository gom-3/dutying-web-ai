# 대화 결과 스냅샷 화면

사용자의 2026-10-03 화면 피드백을 반영한다. 날짜·근무 텍스트 목록을 제거하고 기존 MakeShiftCalendar를 사용하는 넓은 스냅샷 화면으로 연다. 기존 근무 배지, 전달 근무, 행/일자 통계, 그룹 표시를 재사용한다.

불변 결과를 별도 doc으로 변환하며 편집기 store를 변경하지 않는다. readonly/staticPreview로 셀 선택·편집·행 이동을 막는다. 비교는 같은 화면에서 실행 전/결과를 전환한다. 이어서 작성 대상은 현재 표시 중인 실행 전/결과 판본이다. 이어서 작성만 기존 분기 API로 새 대화를 만들고 편집기로 적용한다. Escape/닫기는 현재 작업표로 복귀한다. 대화 입력이나 실행 중 상태와 미리보기의 키보드 이벤트는 분리한다.
