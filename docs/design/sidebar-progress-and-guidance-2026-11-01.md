# 자동채우기 진행 상태와 조절 도움말

자동채우기 직후 조절 예시와 비활성 입력란이 함께 나타나 다음 입력을 요구하는 것처럼 보인다. 진행 단계는 AI 발화로 누적되어 완료 후에도 남는다.

- 계산·요청 확인 중에는 조절 입력란과 예시를 숨긴다. 입력 초안은 유지한다.
- 진행 상태는 현재 상태 한 개로 갱신하고, 완료·실패 후에는 결과 안내만 남긴다. 취소 안내와 결과 재조회·취소 기능은 유지한다.
- 헤더의 초기화는 실제 동작에 맞게 새 요청으로 바꾼다. 근무표·대화 기록 보존 동작은 그대로다.
- 입력란 위에 기본 접힘 도움말을 두고 배정/제외, 횟수, 연속 근무, 야간 후 휴무, 필요 인원, 함께 근무 예시를 묶는다. 후속 요청에서도 열 수 있다.
- 실제 행 순서의 간호사 이름, 현재 월 날짜, 병동의 근무 코드를 사용한다. 야간·휴무·두 번째 간호사가 없으면 관련 예시를 생략한다.
- 예시 선택은 기존 초안에 문장만 추가하고 실행하지 않는다. 입력 길이 500자 제한을 지킨다. 안내에 대상·기간·근무·횟수 작성 요령과 조건 충돌 가능성을 설명한다.

검증: 진행→검토→완료/실패 전환과 재마운트, 진행 중 입력 숨김, 도움말 키보드 토글, 초안 보존, 예시 선택 후 미실행, 사용자 정의 근무 코드와 일본어를 검사한다. 스케줄 계산/API/DB 변경 없음.
