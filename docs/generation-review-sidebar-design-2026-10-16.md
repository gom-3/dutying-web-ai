# 생성 초안 검토 안내 위치 수정

- 문제: 일반 자동채우기에서 검토가 필요한 초안을 받으면 표 위에 별도 노란 배너가 표시된다.
- 변경: 해당 결과는 기존 사이드바를 열어 완료 메시지로 전달한다. 구체적인 미충족 규칙 설명을 보존하고, 설명이 없으면 기존 초안 검토 안내 문구를 사용한다.
- 조절 권한이 없는 사용자도 생성 결과 안내는 읽을 수 있어야 한다. 조절 권한 판정과 규칙 위반 표시는 유지한다.
- 대화형 API 경로는 이미 사이드바에서 검토 결과를 표시하므로 유지한다.
- 검증: 일반 생성의 검토 초안 결과가 사이드바 내부에 표시되는지, 본문 배너가 사라지는지, 권한이 없어도 안내가 열리고 닫히는지 확인한다.
