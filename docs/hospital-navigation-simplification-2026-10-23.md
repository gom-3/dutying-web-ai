# 병원 관리 화면 핵심 기능 정리

- 병원 관리자의 일: 병동에 들어가 근무표 관리, 관리자 초대·담당 병동 지정, 이용 현황과 계약 확인.
- 주 메뉴는 병동 관리 / 관리자 관리 / 이용·계약 3개로 통일한다. 관리자도 이용량을 읽을 수 있지만 계약·금액·결제 조회는 최고 관리자만 한다.
- 초대·최고 관리자 인계 수락은 상단 알림에서 처리한다. 실제 요청이 없으면 빈 초대·인계 양식을 표시하지 않는다. 인계 발신은 관리자 관리의 접힌 설정에 둔다.
- 계정, 개인 결제 기록, 병원·병동 전환은 프로필 메뉴에 둔다. 문의는 공통 문의하기 링크로 제공한다.
- 병원 화면에서 견적 계산, 개별 병동용 추가 구매·구독·카드 등록, 지원 시간, 복잡한 정산·종료 요청 양식을 제외한다. 계약 변경은 문의로 연결한다.
- 이전 사용량 URL은 이용·계약으로, 이전 지원 URL은 이용·계약의 문의 동선으로 연결한다. 초대 URL도 알림으로 연결하여 기존 링크가 끊기지 않게 한다. 독립 병동의 구매·결제 기능은 유지한다.
- 시각 방향: Atlassian의 정보 계층과 Carbon의 명확한 역할 구분을 적용한다. 기존 로고·남색 버튼·회색 면을 재사용하고 장식 선·그림자를 추가하지 않는다. 3개 메뉴와 상단 알림·프로필은 모바일에서도 동일한 순서를 유지한다.
- 검증: 실제 API 호출 권한, 초대/인계 수락·발신, 기존 링크, 독립 병동 결제 회귀, 모바일·키보드·오류 상태. DB·서버 API 변경 없음.
