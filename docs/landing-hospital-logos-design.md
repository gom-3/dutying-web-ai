# 랜딩페이지 병원 로고

## 현재 표시 상태 — 2026-11-14

사용자 요청으로 `develop`의 병원별 로고 표시를 도입 전의 공통 병원 아이콘 레일로 되돌린다. 컴포넌트와 스타일은 로고 도입 이전 버전으로 복구한다. 병원명 순환과 한빛병원을 포함한 152개 목록은 유지한다. 수집한 로고 파일·출처와 드라이브의 로고·연락처 엑셀은 보관하며, 랜딩 컴포넌트에서는 로고 매핑을 불러오지 않는다. 아래 내용은 수집·구현 당시의 기록이다.

## 변경 목적

한국어 랜딩페이지의 병원 이름과 같은 병원의 확인된 로고를 함께 표시한다. 기존 병원 순서는 유지하고 첨부 사용 현황에 누락된 부산 연제구 한빛병원을 마지막에 추가한다.

## 표시와 데이터

- 병원명 목록은 `landing-hospitals.ts`에서 계속 관리한다. 공식 홈페이지에서 확인한 로고의 로컬 경로를 병원명에 연결한다.
- 공식 로고는 정적 파일로 저장하고 원본 페이지와 이미지 URL, 확인 결과를 보조 자료에 기록한다. 동명이거나 기관을 확인하지 못한 이미지는 연결하지 않는다.
- 기존 3.8초 회전 주기는 유지한다. 작은 원 여러 개 대신 현재 병원의 로고 하나를 이름 옆에 표시하여 가로형 로고도 읽을 수 있게 한다. 모바일에서는 로고와 이름을 위아래로 배치한다.
- 로고에는 색상 필터를 적용하지 않고 여백과 `object-fit: contain`으로 비율을 유지한다. 로고 미확보 또는 이미지 로딩 실패 시 기존 병원 아이콘을 표시한다.
- 공식 흰색 로고 7개는 원래 색을 유지한 채 어두운 배경에 표시한다. 긴 이름은 작은 화면에서 줄바꿈하여 가로 스크롤 없이 읽을 수 있게 한다.
- 로고는 옆에 표시하는 이름과 중복되므로 장식 이미지로 처리한다. 기존 동작 줄이기 설정을 유지한다.

## 검증과 반영

기존 랜딩페이지 테스트, 이름·로고 동기화와 미등록·로딩 실패 대체 동작 테스트, 타입 검사와 앱 빌드를 실행한다. 모바일과 데스크톱에서 로고 비율과 긴 병원명의 표시를 확인한다. 검증한 작업 커밋만 `origin/develop`에 반영하며 운영 배포 완료로 표시하지 않는다.

## 구글 검색 보완 기준

- 미확보 43개를 구글 이미지 검색으로 다시 확인한다. 검색 결과에서 찾은 공식 홈페이지·공식 계정의 실제 로고 자산을 우선 사용한다. 공식 페이지의 지연 로딩, 하위 경로, 인라인 SVG, CSS 스프라이트도 확인한다.
- 공식 사이트 접근이 어려우면 병원이 공개한 채용 정보나 협력 병원 소개에서 이름과 지역이 일치하는 로고를 사용할 수 있다. 해당 출처는 공식 홈페이지 자산과 구분하여 `verified-logo`로 기록한다.
- 동명 병원 또는 일반 기업 기본 이미지는 연결하지 않는다. 이미지 출처를 확인하지 못한 병원은 기존 아이콘을 유지한다. 연락처 자료는 별도 엑셀 시트에서 관리한다.
- 대체 아이콘 테스트는 특정 병원의 수집 상태에 의존하지 않도록 로고 누락을 명시적으로 모의한다.

## 2026-11-13 확인 결과

- 병원 152개: 기존 151개 순서 유지, 부산 연제구 한빛병원 추가.
- 로고 149개를 확보했다. 최초 109개에서 구글 검색으로 40개를 추가했다. 공식 홈페이지·공식 계정 자산 144개와 공개 채용정보·협력병원 소개에서 대조한 로고 5개를 구분하여 기록했다. 개별 출처와 대체 여부는 `landing-hospital-logo-sources.json`에 기록했다.
- 대구 M병원, 인제고려병원, 연천 효사랑병원은 로고 원본 검증을 완료하지 못해 기존 아이콘을 유지한다. 미확보는 로고 자체가 없다는 뜻이 아니다. 다른 지역 동명 병원 로고와 일반 기본이미지는 제외했다.
- 정적 로고 전체를 WebP로 최적화하고 실제 배포 파일 SHA-256을 출처 기록에 저장했다. 마산의료원은 운영기관 경상국립대학교병원 홈페이지의 해당 의료원 로고를 사용한다.
- 랜딩 테스트 53개 통과, 변경 파일 ESLint 통과, 타입 검사를 포함한 앱 프로덕션 빌드 통과. 기존 109개 로고와 출처 기록은 변경하지 않았다.
- 최초 구현의 Chromium 검증에서 데스크톱 1440px, 모바일 390px·320px의 길병원·한빛병원·미확보 병원과 긴 병원명에 가로 넘침이 없었다. 이번 보완은 표시 구조를 바꾸지 않았고, 추가 로고는 전체 이미지를 디코딩하고 원본 색상·비율과 흰색 로고 3개의 어두운 배경을 개별 대조했다.
- 반영 대상은 `origin/develop`이다. 운영 `main` 배포와 운영 화면 반영은 확인하지 않았다.
