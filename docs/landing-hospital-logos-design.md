# 랜딩페이지 병원 로고

## 변경 목적

한국어 랜딩페이지의 병원 이름과 같은 병원의 공식 로고를 함께 표시한다. 기존 병원 순서는 유지하고 첨부 사용 현황에 누락된 부산 연제구 한빛병원을 마지막에 추가한다.

## 표시와 데이터

- 병원명 목록은 `landing-hospitals.ts`에서 계속 관리한다. 공식 홈페이지에서 확인한 로고의 로컬 경로를 병원명에 연결한다.
- 공식 로고는 정적 파일로 저장하고 원본 페이지와 이미지 URL, 확인 결과를 보조 자료에 기록한다. 동명이거나 기관을 확인하지 못한 이미지는 연결하지 않는다.
- 기존 3.8초 회전 주기는 유지한다. 작은 원 여러 개 대신 현재 병원의 로고 하나를 이름 옆에 표시하여 가로형 로고도 읽을 수 있게 한다. 모바일에서는 로고와 이름을 위아래로 배치한다.
- 로고에는 색상 필터를 적용하지 않고 여백과 `object-fit: contain`으로 비율을 유지한다. 로고 미확보 또는 이미지 로딩 실패 시 기존 병원 아이콘을 표시한다.
- 공식 흰색 로고 4개는 원래 색을 유지한 채 어두운 배경에 표시한다. 긴 이름은 작은 화면에서 줄바꿈하여 가로 스크롤 없이 읽을 수 있게 한다.
- 로고는 옆에 표시하는 이름과 중복되므로 장식 이미지로 처리한다. 기존 동작 줄이기 설정을 유지한다.

## 검증과 반영

기존 랜딩페이지 테스트, 이름·로고 동기화와 미등록·로딩 실패 대체 동작 테스트, 타입 검사와 앱 빌드를 실행한다. 모바일과 데스크톱에서 로고 비율과 긴 병원명의 표시를 확인한다. 검증한 작업 커밋만 `origin/develop`에 반영하며 운영 배포 완료로 표시하지 않는다.

## 2026-11-13 확인 결과

- 병원 152개: 기존 151개 순서 유지, 부산 연제구 한빛병원 추가.
- 공식 로고 109개를 확보하고 나머지 43개는 기존 아이콘으로 표시한다. 미확보는 공식 로고가 존재하지 않는다는 뜻이 아니다. 개별 출처와 대체 여부는 `landing-hospital-logo-sources.json`에 기록했다.
- 정적 로고 전체를 WebP로 최적화하고 실제 배포 파일 SHA-256을 출처 기록에 저장했다. 마산의료원은 운영기관 경상국립대학교병원 홈페이지의 해당 의료원 로고를 사용한다.
- 랜딩 테스트 53개 통과, 변경 파일 ESLint 통과, 전체 앱 타입 검사와 프로덕션 빌드 통과.
- Chromium에서 109개 로고 모두 디코딩 성공, 페이지 오류 없음. 데스크톱 1440px, 모바일 390px·320px에서 길병원·한빛병원·미확보 병원과 긴 병원명을 확인했으며 가로 넘침이 없다.
- 반영 대상은 `origin/develop`이다. 운영 `main` 배포와 운영 화면 반영은 확인하지 않았다.
