Meta 측정 연동

목적: 웹 가입 성공과 앱 실행·가입 완료를 Meta의 표준 이벤트로 측정한다. AppsFlyer 도입이나 앱 출시, 운영 배포는 포함하지 않는다.

  • 웹: 기존 운영 도메인 픽셀 설정을 사용하고 CompleteRegistration을 GA4와 독립적으로 전송한다. 가입 실패·로그인·체험에는 전송하지 않는다.
  • 앱: facebook_app_events를 사용한다. 자동 초기화·자동 이벤트·광고 식별자·URL 및 화면 메타데이터 수집을 끈다. 명시적으로 활성화한 운영 API 빌드만 수집한다.
  • 앱 설정: Meta App ID와 Client Token은 네이티브 빌드 설정으로 주입한다. 픽셀 ID를 재사용하지 않는다. 미설정 상태에서는 앱 측정을 비활성화한다.
  • 사용자 이름·이메일·전화번호·계정 ID·병동·근무표 데이터는 이벤트 인자로 전송하지 않는다.
  • 검증: SDK 모의 테스트로 성공·실패·운영 환경 제한·중복 초기화를 확인한다. 실제 Meta 수신은 계정 설정 후 별도로 검증한다.

기준: origin/develop. Flutter main에는 별도 LINE 로그인 변경이 있으므로 이 변경을 main에 덮어쓰거나 출시하지 않는다.

검증 결과

웹 측정·운영 도메인 제한·이메일 가입·소셜 가입 테스트 59개 통과. TypeScript 검사 및 변경 파일 ESLint 통과. 실제 Meta 수신은 운영 배포 후 별도 확인해야 한다. 운영 배포는 수행하지 않는다.

이메일 가입은 passwordSignup 성공 직후, 소셜 가입은 최초 프로필 등록 성공 직후에만 가입 완료를 전송한다. 로그인·가입 실패·일반 프로필 수정은 가입 이벤트로 세지 않는다. 기존 픽셀 ID 설정을 유지한다. GA4와 픽셀 설정 및 오류를 독립적으로 처리한다.
