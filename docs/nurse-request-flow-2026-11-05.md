# 수간호사 대화 결과 완결
요청별 검증 결과를 실제 결과 카드에 표시한다. 수치 비교는 Spring 검증 완료 + 횟수 의미가 명확한 지표만 허용한다. 복합 요청은 누락 없이 상태를 보여준다. 조건 양보/정성 후보는 실제 sidebar에 비교·유지·반영 선택을 연결한다. 원본 표 로드 실패/버전 불일치/만료/다른 요청 실행 중에는 적용을 차단한다. 기존 token/digest/cache 선택 경로를 재사용한다. 원본 표와 후보의 전후 근무 목록, 변경 인원/칸 수를 함께 보여준다.

검증: 실제 sidebar 테스트 193개 통과(새 요청별 결과 표시와 캐시 후보 적용 토큰 전달 포함). 결과 요약·원본 조회 실패/재시도·버전 불일치·이전 후보·후보 선택 API 25개 통과. TypeScript 및 신규 컴포넌트 ESLint 통과. UI는 Spring의 displayText/metricKey가 있는 결과부터 요청별 수치를 표시하며, 구버전 결과는 기존 안내를 유지한다. 실제 운영 브라우저/외부 모델 품질 평가는 별도이며 운영 배포하지 않았다.
