# 온보딩 뒤로가기 입력 유지

- 근무 입력 → 근무 유형 → 이전 이동 시 이전 달 근무표 대신 이번 달 빈 표가 열리는 문제가 있다. 근무 입력 화면이 다시 마운트될 때 선택 팀의 저장된 근무표 중 데이터가 있는 최신 월을 연다. 비어 있는 근무표만 있으면 이번 달을 사용한다.
- 근무 유형에서 이전을 누르면 진입 당시 snapshot으로 전체 draft를 되돌리는 코드를 제거한다. 현재 입력과 수정 사항을 유지하고 단계만 바꾸며 기존 서버 자동 저장을 사용한다.
- 엑셀 서식은 브라우저에서 파싱하고 진단 기록만 비동기 전송한다. 기타 엑셀은 서버의 deterministic 파서를 사용한다. 사진의 LLM OCR 경로와 구분되며 엑셀 성공 경로에는 Slack 성공 알림이 없다.
- 검증(2026-11-14): 온보딩 화면 48개 및 wizard hook 38개 테스트 통과. 이전 달 입력 왕복/새로고침 복원과 근무 유형 수정/서버 저장을 포함한다. `pnpm run type-check` 통과. 기존 초기화 기대 테스트는 수정 유지 계약으로 변경했다. DB 스키마 변경 없음. 운영 배포 및 실제 사용자 세션 검증은 미실시다.
