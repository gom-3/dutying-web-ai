# 온보딩 근무 유형: 약자 우선 표시

## 문제와 결정

원본 근무표의 `V` 같은 코드를 `기타 휴가`라는 이름보다 뒤에 보여주면 자동으로 붙인 설명을 병동이 정의한 확정 이름으로 오해하기 쉽다. 엑셀 범례에서 가져온 실제 설명도 있어, D/E/N/O 외 이름을 모두 추정이라고 단정하지 않는다.

- 표의 첫 입력 열을 약자로, 다음 열을 근무명으로 바꾼다. 헤더·행·키보드 이동 순서를 함께 바꾸고 기존 너비를 각 필드에 맞춘다.
- 표 위 안내: 약자를 기준으로 확인하고, D/E/N/O 외 근무명은 자동으로 붙인 임시 설명일 수 있으므로 병동의 이름과 유형으로 확인/수정하도록 안내한다.
- 이 안내를 근무명 입력의 접근 가능한 설명에도 연결한다. 두 입력에 명시적인 열 이름을 연결한다.
- 근무표에서 추출한 값·유형 매핑·API·DB 저장 계약은 바꾸지 않는다. 사용자가 수정한 이름을 추정으로 단정하는 행별 배지는 추가하지 않는다.
