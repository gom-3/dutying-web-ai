# 날짜·요일별 배정 제한 화면 분리

## 실무 판단
병동/그룹의 필요 인원수와 개인의 근무 배정 제한은 목적이 다르다. 인원수 탭에는 전체·그룹 인원 설정만 제공하고, 사람별 제한에는 직원·적용 날짜/요일·근무를 고르는 전용 카드를 제공한다. 개인 배정 제한에서 인원수와 비교 연산자는 노출하지 않는다.

## 구현 범위
기존 STAFF_COUNT_BY_SHIFT / NURSE / EXACT 0 저장 계약을 재사용한다. 별도 서버 룰·DB 변경 없이 추가 화면, 저장된 조건 표시·편집까지 동일한 배정 제한 문장을 사용한다. 기존 MAX 0 개인 조건도 같은 의미로 표시하되 저장값은 보존한다. 전체·그룹 조건은 기존 화면을 유지한다. 두 입력의 임시 상태를 분리하여 탭 이동으로 대상이 섞이지 않도록 한다. 개인 조건은 필수로 추가하며 기존 중요도 전환 정책은 유지한다. 개인 대상이 없으면 추가를 막는다.

## 문구
- 제목: 날짜·요일별 배정 제한
- 문장: {직원}에게 {적용일} {근무} 근무를 배정하지 않아요.
- 설명: 선택한 근무만 제한해요. 다른 근무나 휴무는 배정될 수 있어요. 요일은 매주, 일자는 매월 반복 적용돼요.

## 검증
개인 전용 카드에서 숫자·비교 연산자·전체/그룹 대상 숨김, 날짜/요일 변경 저장, 필수 EXACT 0 계약, 기존 개인 조건 편집, 인원수 카드와 임시 상태 분리를 검사한다. 기존 제약조건 화면 회귀 검사와 타입 검사, 웹 빌드를 실행한다.
