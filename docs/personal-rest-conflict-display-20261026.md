# 개인 휴무 목표 충돌 표시
운영 QA732에서 엔진은 개인 O9/A2를 각각 0일만 배정할 수 있다는 진단을 반환했지만 웹이 새 유형을 인식하지 않아 일반 실패문구로 대체했다.
구조화된 PERSONAL_MONTHLY_REST_CAPACITY_CONFLICT의 인원·근무코드·목표·가능 범위를 검증하고 한국어/영어/일본어로 각 충돌을 표시한다. 서버 title 원문을 임의로 노출하지 않는다. 해결안 검증 여부는 기존 규칙대로 유지하며 해결됐다고 주장하지 않는다.

## 운영 전달 검증
- 엔진은 QA732의 개인 O9/A2 충돌을 동시에 반환했다. 웹 렌더러가 이 유형을 인식하도록 연결했다.
- 지역화 테스트38개, 타입 검사, 프로덕션 빌드 통과.
- 릴리스 병합 메시지의 CI 생략 표시는 Pages 배포도 생략할 수 있으므로 운영 전달 커밋에는 사용하지 않는다. 배포 제공자 결과와 공개 UI를 함께 확인한다.
