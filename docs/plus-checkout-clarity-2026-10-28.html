Plus 결제 진입 개선

2026-10-28 · 개발계 TEST 결제 검증 중 확인된 사용성 개선

‘정확한 금액 확인’을 눌러야 카드 등록이 나타나지만 버튼은 견적 보조 기능처럼 보인다. 상품 선택, 구독 관리, 환불 요청이 가입 전에도 같은 비중으로 보여 다음 행동을 찾기 어렵다.

  • 기존 관리 공간의 흰 배경·짙은 잉크·보라색 브랜드를 유지한다. 가격과 한 개의 주 행동에만 시각적 강조를 둔다. 기존 한글 글꼴, 제목 24px, 가격 32px, 본문 15px, 보조 13px.
  • 구독 전에는 Plus 가격·기본 인원·제공량·편성 인원 입력과 ‘Plus 구독 시작’을 먼저 보여준다. 버튼은 서버 견적만 요청하며 결제·카드 등록을 실행하지 않는다.
  • 금액 확인 → 이메일 인증·카드 등록 → 첫 결제의 순서를 표시한다. 견적 생성 후 금액과 기간을 검토하고 명시적으로 동의한다. 기존 이메일 인증·동의·이벤트 종료 동의·만료·중복 방지 검사를 유지한다.
  • 결제 단계로 이동할 때 검토 제목에 포커스를 옮기고, 만료되면 같은 화면의 ‘결제 금액 다시 확인’으로 복구한다. 입력 변경 시 기존 동의를 해제한다.
  • 현재 구독이 없으면 해지·감원 예약을 숨긴다. 청구 전에는 빈 테이블 대신 안내를, 청구서가 없으면 환불 폼을 숨긴다.
  • 카드번호 오류는 원인과 복구 경로를 보여주되 토스의 임의 메시지나 민감한 콜백을 출력하지 않는다.

색상: 흰색 #ffffff, 잉크 #202631, 보조 #566173, 선 #e5e8ed, 브랜드 #7047c6. 휴대폰에서는 한 열, PC에서는 상품 요약과 시작 입력을 두 열로 배치한다. 가격·정책·결제 API·계약 조건·운영계 설정은 변경하지 않는다.
