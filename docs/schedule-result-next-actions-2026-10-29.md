# 성공한 근무표 다음 행동

성공 직후 같은 입력을 다시 생성하는 선택 대신 표 직접 편집과 원하는 변경을 적는 조절을 제공한다.
편집 선택은 채팅을 닫고 기존 편집기로 이동하며 생성/해석 API를 호출하지 않는다.
최초 빈 표의 자동완성, 조건/수동 편집 뒤 자동완성, 시스템·통신 실패 복구는 기존 경로로 유지한다.
조절 입력 중 별도의 자동완성 전환 버튼은 제거한다.

직접 편집으로 나갈 때 마지막 생성 기준이 없다면 현재 표를 기준으로 기억한다.
기존 생성 성공 시에도 결과가 실제 적용된 최신 문서를 기준으로 기억한다.
그 뒤 자동완성 준비에서는 기존 고정/신청과 사람이 바꾼 채워진 칸만 보호하고,
변경하지 않은 AI 결과 전체를 고정하지 않는다. 새 대화로 준비를 취소하면 추가한 고정만 되돌린다.
패널을 닫아 잠시 편집하는 동작은 기존대로 준비 내용을 유지한다.
빈칸으로 지운 자리는 자동완성 대상으로 남고, 편집기로 나간 직후 표를 비우지 않는다.
레거시 생성의 빈칸 계산용 입력을 부분 결과 적용 기준으로 재사용하지 않고 현재 표에 결과를 합친다.

프롬프트 조절은 현재 초안을 sync한 뒤 ADJUST로 실행하는 기존 경로를 유지한다.
고정 확인에서 바뀐 source는 기존 refreshPlan으로 재결합한다. GENERATE로 우회하지 않는다.
최소 변경량 목적함수와 HARD 규칙, 후보 바인딩, 예외 동의, 원래 fillPolicy는 그대로다.

관련 회귀만 확인한다: 성공 후 편집 무실행/문서 보존, 프롬프트→최신 draft ADJUST,
수동 편집 후 자동완성의 일부 고정 및 취소, 최초 생성과 실패 재시도 유지.
새 카드·설정·모드는 없다. 대화 재작성 연결에 필요한 최소 서버 계약 보완은
`conversation-rebuild-intent-2026-10-29.md`에 이어서 기록한다.
