# 사용자 피드백 완료 기준

## 의도와 계약
- 월 휴무 목표는 인원을 제거하거나 조절해도 유지한다. 불가능하면 부족한 표를 정상 완료로 반환하지 않는다. 기존 monthlyRestRequirement 구현을 GENERATE/ADJUST 공통 최종 검사까지 검증한다.
- 전달 확정본은 직원의 영속 ID로 연결한다. 월별 행 ID 변경, 재확정, 편집 화면 재진입을 포함한다. 최신 develop의 구현과 회귀 검사를 재사용한다.
- 개인별 월 N 횟수는 MIN/MAX/EXACT 모두 저장하고 실제 해에 적용한다. 기존 SHIFT_COUNT_PER_PERIOD 계약을 UI에서 노출한다.
- 특정 직원의 날짜/요일 E 제외는 기존 STAFF_COUNT_BY_SHIFT 대상/날짜/EXACT 0 계약으로 표현한다. 별도의 서버 룰을 중복 생성하지 않고 화면에서 쉽게 찾도록 한다.
- 연차 월 최소 1일은 일반 휴무와 구분한다. ANNUAL_LEAVE로 분류된 특정 근무를 명시적으로 선택한 월별 개인 합계 MIN/EXACT 양수 조건만 자동 배정을 허용한다. 지정되지 않은 직원에게 전파하지 않는다. OTHER_LEAVE는 계속 자동 생성 금지다.

## 연차 안전 범위
기존의 연차 자동 배정 금지를 전역 해제하지 않는다. 명시적 대상과 조건에 한해 생성 도메인을 확장한다. 자동 생성량은 요청 횟수와 기존 입력량 중 큰 값까지 제한하여 휴무 최적화가 연차를 과다 배정하지 못하게 한다. 고정 입력은 보존하며, 개인 허용 근무 설정과 충돌하면 몰래 우회하지 않는다. 실제 연차 잔액 차감/검증은 기존 확정 서비스가 담당하며 초안 생성이 잔액을 변경하지 않는다.

## 회귀 검사
월 휴무 9→8 금지, 인원 삭제, 불가능한 고정 입력, 일반 휴무/연차 분리, 개인 N MIN/MAX/EXACT, 대상 외 연차 생성 금지, OTHER_LEAVE 생성 금지, 고정 연차 보존, 선택 취소 후 기존 동작, 요일/날짜 E 제외를 검사한다. 구 계약에 새 필드를 필수화하거나 DB 스키마를 변경하지 않는다.
