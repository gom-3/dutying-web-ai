# 충돌 선택 화면 사용성 점검

목적: 자동완성/조절이 막힌 뒤 수간호사가 다음 행동을 선택하고 실패해도 다시 진행할 수 있어야 한다.

## 확인한 문제와 수정
| 현재 문제 | 변경 |
|---|---|
| 요청 바꾸기를 누르면 카드가 영구적으로 비활성화됨 | 입력 이동은 실행 잠금으로 취급하지 않음. 다른 선택으로 돌아올 수 있음 |
| 제안 적용 중 버튼 문구가 그대로이며 Promise 거절을 처리하지 않음 | 진행 중 문구와 접근성 상태, 카드 내 실패 안내 및 재시도 제공 |
| 화면을 둔 채 제안이 만료돼도 적용 버튼이 활성 상태로 남음 | 만료 시 상태 갱신, 클릭 시에도 시간 재확인 |
| 버튼이 form 내부에 있으면 기본 제출 가능 | 모든 선택 버튼에 type=button 명시 |

검증: 실제 컴포넌트 테스트에서 실패/재시도, 중복 실행 방지, 만료 시간 경과, 요청 수정 후 다른 선택, 부모 form 제출 방지를 확인한다. 가상 간호사로 로컬 화면을 확인하며 운영 입력/근무표는 수정하지 않는다.

범위: 이 수정은 충돌 검토 카드의 복구 동작이다. 상위 화면의 네트워크 오류는 기존 공통 오류 처리도 유지한다. LLM 이해 정확도/운영 생성 시간 개선이나 실제 간호사 사용성 인터뷰 결과를 의미하지 않는다.

## 결과
- 충돌 카드 9개, 대화 사이드바 136개, 만족도 4개: 총 149개 통과. 타입 검사 통과.
- 약 319px 브라우저 화면에서 실제 컴포넌트의 줄바꿈과 버튼 노출 확인. 요청 변경 시 입력 포커스, 이후 제안 적용 → 가상 통신 실패 → 재시도 성공 확인.
- 임시 로컬 화면은 검증 후 삭제. 운영 사용자 데이터는 사용하지 않음.
