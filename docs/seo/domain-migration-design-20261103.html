듀팅 도메인 이전 SEO·AEO 개선

2026-11-03 · 대상: gom-3/dutying-web-ai. 기준 커밋 b7942dfb. 기존 작업 폴더를 보존하고 origin/develop의 별도 worktree에서 작업한다.

관찰한 사실

Search Console 최종 데이터, 미국 태평양 날짜 2026-10-01~10-30: .ai 84회 노출·20클릭·평균 5.70위, .net 2,278회 노출·167클릭·평균 5.02위. 브랜드 ‘듀팅’은 .ai 평균 4.14위, .net 평균 1위다. 이 기간은 이전 전후를 구분하지 않은 기준선이며 리다이렉트 효과의 인과 증거가 아니다.

공개 www.dutying.net/은 308로 www.dutying.ai/에 이동한다. .ai 루트는 200, self-canonical, robots 허용, 6개 언어 sitemap을 제공한다. 현재 sitemap의 privacy/terms는 첫 HTML 본문이 없는 SPA다. 다른 앱 정적 경로들도 홈 메타데이터와 index를 복제한다. docs의 첫 페이지·시작하기·FAQ·모바일 문서는 구축 초안 설명이 주 내용이다.

변경 범위

  • 한국어 검색 제목·설명에 ‘듀팅’, ‘간호사 근무표’, ‘자동 생성’과 검증된 기능을 명확히 제시한다. 웹사이트·회사·앱·페이지의 JSON-LD 식별자를 구분하고 한국어 브랜드명을 연결한다.
  • 마케팅 6개 언어만 앱 sitemap에 포함한다. 비마케팅 앱 경로는 noindex, follow와 자체 canonical을 제공하며 홈 hreflang·제품 schema 복제를 제거한다. preview의 noindex를 유지한다.
  • 공개 docs를 사용자 중심 설명, 근무표 작성 안내, 교대근무 캘린더, 실제 FAQ로 보강한다. 각 문서에 고유 description, canonical, WebPage와 BreadcrumbList를 제공한다. docs preview는 index를 허용하지 않는다.
  • 랜딩의 기존 footer에 한국어 가이드 링크를 추가해 실제 링크로 새 콘텐츠를 발견하게 한다. 레이아웃 재설계나 앱 동작 변경은 하지 않는다.
  • 실제 HTTP 리다이렉트와 canonical·robots·sitemap·JSON-LD를 반복 검증할 수 있는 읽기 전용 공개 감사 명령을 추가한다. 순위 보장, 가짜 리뷰, 지원이 확인되지 않은 FAQ 리치 결과 약속은 하지 않는다.

검증과 통합

앱/문서 production 빌드와 산출물 SEO 검증, preview noindex 검사, 관련 랜딩 테스트 및 타입 검사를 로컬에서 실행한다. remote develop 최신 상태에 통합하고 직접 develop으로 push한다. Actions는 push 트리거가 없는지 확인하고 불필요한 원격 실행은 만들지 않는다. 운영 main 승격·외부 배포는 별도 명시 승인 대상이다. .net 서비스는 수정하거나 재시작하지 않는다.

검색 서비스 후속 작업

도메인 변경 도구 상태·사이트맵 등록·대표 URL 색인 상태를 읽기 전용으로 확인한다. 현재 Google 연결은 읽기 전용이므로 주소 변경 신청·사이트맵 제출의 실행 여부를 추측하지 않는다. 네이버와 외부 스토어·공식 프로필의 .ai 링크는 별도 계정 권한으로 확인해야 한다. 영구 리다이렉트는 최소 1년 유지한다.
