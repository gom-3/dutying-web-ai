# 홈 첫 접속의 국가별 언어 이동

`www.dutying.ai/`와 개발계의 주소창·북마크 직접 진입만 기존 Pages Worker에서 처리한다.
Cloudflare가 요청에 붙이는 국가 코드로 일본은 `/ja`, 미국은 `/en`, 중국은 `/zh`, 태국은 `/th`, 베트남은 `/vi`, 한국 및 그 외 국가는 `/`를 선택한다.
첫 언어와 랜딩 메뉴에서 직접 고른 언어는 같은 브라우저의 호스트 전용 쿠키에 저장한다.
이후 직접 진입에는 저장한 값을 우선하고, 메뉴에서 선택한 값으로 덮어쓴다.
쿠키에는 언어 코드만 저장한다.

홈 링크를 따라 들어오거나 크롤러가 요청하면 기존 한국어 HTML을 제공한다.
언어가 지정된 경로와 `?lng`, 로그인·초대·앱 경로는 기존대로 처리한다.
국가·선택으로 이동할 때는 현재 도메인의 언어 경로에만 임시 302로 보내며 쿼리는 보존한다.
사용자별 리디렉션과 쿠키를 발급하는 응답은 공유 캐시에 저장하지 않는다.

각 언어의 정적 HTML, canonical, hreflang, sitemap을 유지한다.
운영 배포 후 실제 미국·일본·중국·태국·베트남의 직접 진입, 한국어 유지, 선택 재방문, 크롤러의 HTML 및 명시 언어 URL을 확인한다.
배포 범위는 기존 .ai Pages이며 .net 전환 Worker와 DNS에는 변경이 없다.
