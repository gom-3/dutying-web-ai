.ai 대표 검색 주소 이전 후속 처리

2026-11-04 · 목적: .net으로 남아 있는 검색 결과의 대표 주소를 www.dutying.ai로 이전.

확인·처리한 사항

  • bare/www .net의 HTTP/HTTPS 네 변형이 Cloudflare에서 https://www.dutying.ai/로 직접 HTTP 301 이동하는 것을 확인했다.
  • 구글: 11월 3일 접수한 루트 도메인 이전에 이어, 11월 4일 www.dutying.net 이전도 홈페이지 리다이렉트·소유권 검사를 통과하고 이동 확인까지 완료했다. Search Console에 ‘이전 중’, 새 사이트 dutying.ai, 시작일 2026년 11월 4일이 표시됨을 확인했다. 이는 신청 접수이며 검색 결과 교체 완료를 의미하지 않는다.
  • 네이버: 관리 계정 로그인 후 https://www.dutying.ai가 등록됐지만 소유 확인 대기임을 확인했다. 현재 계정이 요구하는 확인 코드는 운영 HTML의 기존 메타 태그 코드와 다르다. 다른 소유자의 확인 태그를 지우지 않도록 네이버가 제공한 HTML 파일 방식을 사용한다.

이번 변경

네이버 공식 다운로드의 67바이트 원본 파일 naverb0ecf482534f7fa837c88fc96af7e302.html을 앱 public에 추가했다. 기존 메타 태그는 유지한다. 확인 응답은 정상 수집 가능하게 제공하되 Cloudflare 헤더에서 noindex로 지정해 해당 파일 자체가 검색 결과 페이지가 되지 않게 한다. 빌드 SEO 검증은 검증 응답의 정확한 본문을 확인하고 일반 페이지 검사와 구분한다.

검증

앱·문서 production 빌드 통과. 44개 일반 앱 HTML·12개 공개 문서의 SEO 산출물 검증 통과. 확인 파일은 네이버 원본과 바이트 단위로 동일하고, 배포 산출물의 noindex 헤더도 확인했다. Prettier·git diff --check 통과. 정적 확인 파일 추가이므로 별도 앱 동작 테스트를 추가하거나 원격 Actions를 재실행하지 않는다.

배포 경계와 다음 단계

이 변경은 최신 origin/develop의 격리된 worktree에서 준비했으며 .net 서비스·Vercel·DNS·기존 .ai 앱 동작은 수정하지 않는다. 운영 배포는 아직 수행하지 않았다. 승인 후 현재 운영 코드에 이 작업 변경만 반영하고, Cloudflare 제공자 커밋·공개 확인 파일 응답을 확인한다. 이어 네이버 소유 확인, .ai 사이트맵 제출, 주요 URL 수집 요청을 진행하고 결과 화면을 검증한다.

검색엔진의 반영 시간과 실제 검색 결과 주소 변경은 이후 수집·색인 상태로 판단한다. 자동 모니터나 유료 구독은 생성하지 않는다.
