# 직원별 월간 근무 횟수 입력 복구

서버와 생성기는 SHIFT_COUNT_PER_PERIOD의 MIN/MAX/EXACT, MONTH, 개인 대상을 지원하지만 웹의 교대제별 노출 목록에 빠져 있었다. 기존 계약을 재사용하여 세 교대제 모두 사람별 제한에서 노출한다. COUNT_OPERATOR/countOperators를 기존 인원 조건 선택지와 동일한 MIN/MAX/EXACT로 연결한다. 기본값은 월간·개인별 집계이며 기존 저장 규칙과 중요도는 바꾸지 않는다. 야간전담 연차 소진은 별도의 연차/휴무 정책이며 야간 횟수로 대체하지 않는다.
