# 사이드바 추가 검토 설계

기존 PR #57 후속. 로컬/모델 결과가 비동기로 도착하는 동안 사용자 의도가 바뀌는 경계를 검토한다.

1. applyCompleted는 결과 조회 전에만 편집 revision을 확인한다. 조회 후 적용 직전 다시 확인하여 수동 편집 보존.
2. pendingBranch 재개도 sync 대기 중 편집 revision 재확인. 새 요청/정상 분기 전환 때 이전 pendingBranch와 선택 제안을 제거.
3. 실패 제안은 최초 선택뿐 아니라 실행 직전 서버 동기화 이후 revision/해석/context/만료/검증 상태를 확인. 두 화면이 같은 조건을 사용하도록 작은 판정 함수 공유.
4. 자주 쓰는 요청 수정 대상을 다른 요청 선택/새 요청/요청 전송 후 초기화. 삭제 후 수정 대상도 초기화. 실행 중 저장 요청 버튼으로 입력을 바꾸지 못하게 함.
5. 입력 오류에는 무관한 결과 조회 버튼을 표시하지 않음. 실행 결과 확인 자체는 계산 중에도 가능.

모델, 승인 정책, API 형식, DB 변경 없음. 재현 테스트와 관련 테스트/타입/린트로 검증 후 기존 PR 갱신. 운영 배포 없음.
