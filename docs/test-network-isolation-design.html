2026-10-03 인증 경보 재발 방지

온보딩 페이지 테스트는 shared/api의 FileAPI만 대체하여 HospitalAPI가 실제 서버를 호출했다. 테스트 서버 URL 기본값과 운영 환경 설정에 따라 무인증 요청이 운영으로 나갔다.

온보딩 병원 검색을 명시적으로 모킹한다. Vitest 공통 설정에서 모킹되지 않은 fetch와 XMLHttpRequest를 전송 전에 차단하고, 테스트가 오류를 잡아도 afterEach 검증으로 누락을 실패시킨다. API URL 테스트와 명시적인 네트워크 모킹은 유지한다. 실제 앱 코드와 인증 경계는 변경하지 않는다.

차단 회귀 테스트, 온보딩 테스트 및 전체 Vitest로 검증한다.
