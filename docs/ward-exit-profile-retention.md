# 병동 탈퇴 후 계정 프로필 유지

병동 탈퇴 API는 membership을 LEFT로 바꾸고 현재 병동을 해제하며 계정 이름/연락처/프로필 이미지는 수정하지 않는다. 그런데 웹 RegisterPage가 WORKSPACE_SETUP_PENDING이면서 연락처가 없는 모든 계정을 신규 가입처럼 취급해, 탈퇴 뒤에도 계정 정보 입력을 강제했다. RegisterNurse에는 저장된 연락처를 폼에 채우는 처리도 없었다.

- 탈퇴 성공 후 전달하는 fromQuitWard 경로에서는 연락처 입력을 다시 강제하지 않고 병동 선택으로 이동한다. 이 router history state는 새로고침에도 유지된다.
- 신규 계정의 연락처 수집은 유지한다. 서버 연락처 유실을 추정해 번호를 생성하거나 데이터를 보정하지 않는다.
- 계정 정보 편집 화면에는 기존 연락처를 초기값으로 제공하고, 병동 미선택 상태에서도 기존 프로필 이미지를 사용한다.
- 기존 연락처 입력란을 사용자가 지운 뒤 재입력을 강제로 덮어쓰지 않는다. 계정의 저장된 연락처가 변경될 때만 초기화한다.
- DB 스키마/API 변경 및 Flyway migration 없음. 실제 QA 계정의 연락처 저장 여부는 코드만으로 단정하지 않는다.

검증: 탈퇴 후 연락처 유무별 병동 선택 이동, 신규 연락처 수집 유지, 기존 프로필/연락처 초기값과 편집 동작 회귀 테스트.

2026-11-14 검증: RegisterPage/RegisterNurse/병동 탈퇴 hook 관련 33개 테스트 통과. 변경 파일 ESLint/Prettier 통과. 신규 계정의 연락처 수집 테스트를 유지했다. 운영 배포 및 실제 연락처 삭제 여부에 대한 DB 검증은 수행하지 않았다.
